# Girlfriend Day Observatory

A completely separate Happy Girlfriend Day website concept.

## Concept

Instead of another game hub, this is a private digital observatory:
- clickable constellation of reasons
- “Open when...” message capsules
- future-memory generator
- ridiculous obsession meter
- hold-to-open final love letter
- animated night sky

## Publish with GitHub Pages

1. Create a new repository, e.g. `girlfriend-day-observatory`.
2. Upload `index.html`, `styles.css`, `script.js`, and `.nojekyll` to the repository root.
3. Commit.
4. Open **Settings → Pages**.
5. Select **Deploy from a branch**.
6. Select **main** and **/(root)**.
7. Save and wait for deployment.

No external images or API keys are required.
